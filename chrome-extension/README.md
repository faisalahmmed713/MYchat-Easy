# MYchat Easy for Chrome

Translate, rewrite, write and reply in any text box on the web, with your own AI key.

## Install for testing
1. Open `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and select this `chrome-extension` folder.

## Publish to the Chrome Web Store
Zip the **contents** of this folder (so `manifest.json` is at the top of the zip) and upload it in the
[Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole).
Store images and the privacy policy are in `../store-assets`.
